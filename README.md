# Global Tech Layoffs Analysis | Power BI Dashboard

## Project Overview
This project analyzes global technology layoffs to identify trends across years, companies, industries, countries, and funding stages. An interactive Power BI dashboard was developed to present key insights through visualizations, KPI cards, filters, and page navigation.

## Objectives
- Analyze layoff trends over time.
- Identify companies with the highest reported layoffs.
- Compare layoffs across industries and countries.
- Examine layoffs by company funding stage.
- Build an interactive dashboard to support data-driven insights.

## Tools Used
- **Power BI** – Dashboard development and visualization
- **DAX** – Measures and calculations
- **Kaggle Dataset** – Global Tech Layoffs Analysis

## Dashboard Pages

### 1. Executive Overview
- Total layoffs and companies affected
- Countries and industries affected
- Monthly and yearly layoff trends
- Top companies by layoffs

### 2. Industry & Company Analysis
- Top industries by total layoffs
- Top companies by total layoffs
- Industry contribution analysis
- Industry-to-company drill-down using a Matrix visual

### 3. Geographic & Funding Analysis
- Global layoffs by country using a map
- Top countries by layoffs
- Layoffs by funding stage
- Country and funding-stage slicers

### 4. Detailed Company Analysis
- Year-wise layoff trends
- Top companies by layoffs
- Company-related details by country and industry
- Interactive report navigation and filters

## Key Insights
- **2023** recorded the highest layoffs in the displayed yearly trend.
- **Intel** ranked first in the dashboard's Top 10 companies chart.
- The **United States** recorded the highest total layoffs among countries.
- **Hardware** was among the industries with the highest reported layoffs.
- **Post-IPO** companies had the highest total layoffs among the funding stages shown.

## Dataset
Source: [Global Tech Layoffs Analysis – Kaggle](https://www.kaggle.com/datasets/blixture/global-tech-layoffs-analysis-dataset/data)

The dataset includes information such as company, country, industry, funding stage, layoff count, layoff date, and year.

## Limitations
- The dataset does not provide a confirmed workforce layoff percentage for calculating the proportion of each company's employees laid off.
- A funding amount field was not available in the final Power BI fields, so a funds-raised-versus-layoffs scatter plot could not be completed.
- Findings represent the records available in the dataset and may not cover every layoff event worldwide.

## Conclusion
This project demonstrates how Power BI can be used to analyze layoff data, compare trends across multiple dimensions, and communicate business insights through interactive dashboards.
